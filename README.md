# ☕ ONGI CAFE 랜딩페이지

작은 동네 카페를 소개하는 간단한 원페이지(One-page) 랜딩페이지입니다.

## 📌 소개

ONGI CAFE는 직접 로스팅한 원두와 매일 굽는 디저트를 소개하는 가상의 카페 브랜드입니다.
이 프로젝트는 별도의 프레임워크 없이 순수 HTML/CSS/JS로 제작한 반응형 랜딩페이지입니다.

## 🗂 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 (히어로 / 소개 / 메뉴 / 갤러리 / 오시는 길) |
| `style.css` | 브라운·크림 톤의 반응형 스타일 |
| `script.js` | 스크롤 시 헤더 그림자 효과 |

## 🖥 미리보기 섹션

- **Hero** — 카페 대표 문구와 CTA 버튼
- **About** — 카페 소개 및 특징
- **Menu** — 시그니처 메뉴 4종
- **Gallery** — 매장 갤러리
- **Location** — 주소, 영업시간, 연락처, 지도 영역

## 🚀 실행 방법

별도 빌드 과정 없이 `index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

```bash
git clone https://github.com/jsojeong35/cafe-landing.git
cd cafe-landing
# index.html을 브라우저로 열기
```

## 🛠 사용 기술

- HTML5
- CSS3 (Flexbox, Grid, 반응형 미디어쿼리)
- Vanilla JavaScript
